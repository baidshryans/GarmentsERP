Behaviour notes

  • Replace the current <input list="party_list"> + native <datalist> with the existing SearchableComboBox component (already used on the Sales Voucher page).
  • Search keys: ac_name, mobile1, mobile2, phone1 — typing digits matches phones; typing letters matches name.
  • Each row shows name on top, phone · city on the second line, with the matched substring highlighted.
  • On select: set form.ldgr (id) + form.ldgr_code_name (display), and reveal the read-only info card with phone (mobile1 / phone1) and address (add1, add2, city, state, pincode joined).
  • Clearing the field hides the info card and resets form.ldgr.
  • The trailing + button keeps its existing behaviour — link to /crm/ledger/add/?next=… to add a new customer.
