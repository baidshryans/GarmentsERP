B1 — Grouped headers + rowSpan (recommended)

Same 22 fields, reorganised. The four lifecycle groups (Issue / Broken / Return / Balance) get merged headers in subtle violet bands. Main piece columns (Main SL · Pcs · GW) collapse to one cell that spans every sub-row of that piece via rowSpan, so they don't repeat. Loss values (Broken > 0) flag in red. Totals row at the bottom. Same palette as the Stone Detail redesign.

B2 — Compact stage cells (no horizontal scroll)

Same idea as B1 but each lifecycle stage collapses to one cell with three stacked numbers — pieces bold, carats regular, weight light. Drops the table from 22 columns to 11 so it fits the panel without horizontal scroll on most screens. Pick this if you want the panel to be readable at a glance without scrolling sideways.
